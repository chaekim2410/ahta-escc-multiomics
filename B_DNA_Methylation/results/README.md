# B results: methylation and DMR outputs

| File | Meaning |
|---|---|
| `EntrezIDs_CpG_results.txt` | Entrez IDs associated with significant differentially methylated CpGs. |
| `EntrezIDs_bmp_results.txt` | Entrez IDs associated with significant `bumphunter` DMRs. `bmp` refers to bumps/regions. |
| `CpG_GSA_results.txt` | GO enrichment results for CpG-associated genes. |
| `bmp_GSA_results.txt` | GO enrichment results for DMR-associated genes. |

The CpG and DMR tables are gene-level summaries of two different methylation views: individual probes versus nearby probes acting as a region. The GO tables translate those gene lists into biological processes.
