# D results: integration inputs

| File | Used for |
|---|---|
| `RNAseq_results.txt` | Significant/sorted RNA-seq genes. |
| `EntrezIDs_CpG_results.txt` | Genes associated with significant methylated CpGs. |
| `EntrezIDs_bmp_results.txt` | Genes associated with significant DMRs. |
| `RNAseq_GSA_results.txt` | RNA GO terms. |
| `CpG_GSA_results.txt` | CpG-based methylation GO terms. |
| `bmp_GSA_results.txt` | DMR-based methylation GO terms. |

These files are the inputs to the Venn and shared-GO comparisons in `Comparison.Rmd`.
