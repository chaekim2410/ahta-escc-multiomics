# Generated methylation figure assets

This directory was created automatically when the original methylation R Markdown notebook was rendered. The figures are preserved as original build artifacts; the generic `unnamed-chunk-*` filenames correspond to unnamed code chunks in `Methylation_Analysis.Rmd`.

The files themselves are stored under [`figure-latex/`](figure-latex/). See [`figure-latex/README.md`](figure-latex/README.md) for a file-by-file description.

These PDFs support the data-inspection and raw-QC sections of the methylation notebook. They are not separate datasets or independent analysis results.
